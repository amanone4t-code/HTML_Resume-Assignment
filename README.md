# Resume Website using HTML

This project is a simple single-page resume website created using only HTML.  
The main objective of this assignment is to practice and demonstrate the use of basic HTML structure and semantic tags without using CSS.

## Features

- Single-page resume layout
- Clean and readable HTML structure
- Uses semantic HTML tags
- Includes multiple resume sections:
  - Header/Profile
  - About Me
  - Skills
  - Experience
  - Projects
  - Education
  - Certificates
  - Contact Details
- Uses headings, paragraphs, lists, tables, and sections properly
- Beginner-friendly project

## Technologies Used

- HTML5

## Project Structure

```bash
resume-website/
│
├── index.html
└── README.md
```

## Purpose of the Project

The purpose of this project is to understand:

- Basic HTML page structure
- Semantic HTML elements
- Lists and tables in HTML
- Organizing content in sections
- Creating a resume webpage without styling

## How to Run the Project

1. Download or clone the repository
2. Open the project folder
3. Open `index.html` in any web browser

## Output

The webpage displays a complete resume in a structured format similar to a professional portfolio/resume layout.

## Learning Outcomes

After completing this project, you will understand:

- How to structure webpages using HTML
- Proper usage of semantic tags
- Creating tables and lists
- Organizing resume information effectively
- Building a basic portfolio/resume webpage
